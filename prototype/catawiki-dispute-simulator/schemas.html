Safe rename: update every consumer → add the new optional field and keep the old one → publish both → remove the old field after all consumers move. BACKWARD checks the latest prior version; BACKWARD_TRANSITIVE checks all prior versions. This demo uses the default <topic>-value subject and puts the schema ID in the value; Confluent can also put a schema GUID in a Kafka header. The subject and IDs are examples. This is a teaching model; Registry enforcement was not identified in the four audited Catawiki apps.
